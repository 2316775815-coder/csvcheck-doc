1. 工具概述

CSV Check 是一款命令行工具，用于检查学生成绩 CSV 文件是否包含指定的必需列名。它帮助使用者在将成绩表提交给导入系统之前，快速确认文件的列结构是否符合要求。

核心功能

  • 读取 CSV 文件的表头行，检查是否包含指定的必需列（默认 id、name、score）
  • 统计有效数据行数（不含表头）
  • 检测表头结构问题：空表头、重复表头、行列数不一致
  • 支持通过 --require 参数自定义必需列
设计边界：本工具只检查列名是否存在，不校验分数值的正确性，也不执行实际数据导入。Result: PASS 仅表示列结构符合要求。

3. 快速开始

  1. 打开终端，进入 01_写作练习 目录
  2. 确认同目录下有 check.py、csvcheck/、samples/
python check.py samples/students.csv

看到 Result: PASS 即表示检查通过。

若系统命令为 python3 或 py，替换开头即可。

4. 命令行参数详解

python check.py <file> [--require COLUMN [COLUMN ...]]
参数类型必填默认值说明
file位置参数是—输入 CSV 文件路径
--require选项否id name score必需列名，空格分隔，大小写敏感

自定义必需列示例：

python check.py samples/students.csv --require id score

7. 退出码说明

退出码含义触发条件
0通过所有必需列均存在（PASS）
1未通过缺少必需列（FAIL）
2文件错误无法读取、无表头、结构错误等（ERROR）
macOS/Linux 用 echo $? 查看，Windows 用 echo %errorlevel%。

8. 故障排查

错误信息原因解决方法
File has no header.文件为空或无表头确认首行为列名行
Header names must not be blank.表头有空列名检查多余逗号
Header names must be unique.表头重复重命名重复列
Row N has X fields; expected Y.某行字段数不符修正该行逗号数量
Cannot read a UTF-8 CSV file编码非 UTF-8另存为 UTF-8
python: command not found命令名不同改用 python3
No module named 'csvcheck'check.py 被移出原目录放回 csvcheck 同级目录
排查优先级：先检查工作目录和文件结构，再考虑 Python 安装。不要反复重装 Python。

9. 源码结构

工具由 check.py（入口）、csvcheck/__init__.py（核心逻辑）、csvcheck/__main__.py（包级入口）组成。

check.py — 命令行入口

  • 导入 argparse、sys、csvcheck
  • main()：解析参数 → 调用 inspect_csv → 打印报告 → 返回退出码
  • 捕获 CsvCheckError 返回 2；PASS 返回 0；FAIL 返回 1

csvcheck/__init__.py — 核心逻辑

  • __version__ = "1.0.0"
  • CsvCheckError(ValueError)：自定义异常
  • inspect_csv(path, required_columns=())：打开文件 → 校验表头 → 遍历行 → 返回字典
  • format_report(report)：格式化为 JSON 字符串

inspect_csv 返回字典结构：

{
  "columns": ["id", "name", "score"],
  "row_count": 3,
  "missing_columns": [],
  "valid": true
}

csvcheck/__main__.py — 包级入口

  • 支持 python -m csvcheck 运行，输出 JSON 报告
  • 额外支持 --version 参数，错误输出到 stderr
