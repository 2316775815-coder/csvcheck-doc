1. Overview

CSV Check is a command-line tool that verifies whether a student grade CSV file contains the required column names. It helps you confirm that a file's column structure meets requirements before you submit it to an import system.

Core Features

  • Reads the header row of a CSV file and checks for required columns (default: id, name, score)
  • Counts valid data rows (excluding the header)
  • Detects structural issues: blank headers, duplicate headers, mismatched column counts
  • Supports custom required columns via the --require option
Boundary: This tool only checks whether column names exist. It does not validate score values and does not perform the actual import. A Result: PASS only means the column structure is correct.

3. Quick Start

  1. Open a terminal and navigate to the 01_写作练习 folder
  2. Confirm that check.py, csvcheck/, and samples/ are present
python check.py samples/students.csv

A Result: PASS line means the check passed.

If your system uses python3 or py, replace the first word accordingly.

4. CLI Reference

python check.py <file> [--require COLUMN [COLUMN ...]]
ArgumentTypeRequiredDefaultDescription
filePositionalYes—Path to the input CSV file

Example with custom required columns:

python check.py samples/students.csv --require id score

6. Expected Output

Scenario A: All columns present → PASS

CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: none
Result: PASS
PASS checks column names, not score values.

Scenario B: Missing column → FAIL

CSV Check 1.0.0
File: samples/missing-name.csv
Data rows: 1
Columns: id, score
Missing columns: name
Result: FAIL

Scenario C: Empty file → ERROR

CSV Check 1.0.0
ERROR: File has no header.

9. Source Structure

The tool consists of check.py (entry point), csvcheck/__init__.py (core logic), and csvcheck/__main__.py (package entry point).

check.py — CLI Entry Point

  • Imports argparse, sys, csvcheck
  • main(): parses args → calls inspect_csv → prints report → returns exit code
  • Catches CsvCheckError → returns 2; PASS → 0; FAIL → 1

csvcheck/__init__.py — Core Logic

  • __version__ = "1.0.0"
  • CsvCheckError(ValueError): custom exception
  • inspect_csv(path, required_columns=()): opens file → validates header → iterates rows → returns dict
  • format_report(report): formats the report as a JSON string

The inspect_csv return value:

{
  "columns": ["id", "name", "score"],
  "row_count": 3,
  "missing_columns": [],
  "valid": true
}

csvcheck/__main__.py — Package Entry Point

  • Run with python -m csvcheck, outputs a JSON report
  • Supports the --version flag; errors go to stderr
